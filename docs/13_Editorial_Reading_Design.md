# Editorial Reading Design

The public article body uses a deliberately distinct long-form reading system:

- branded sans-serif for headlines and navigation;
- a newspaper-style serif stack for article copy;
- a narrower reading measure;
- larger opening paragraph with a drop cap on desktop;
- visibly differentiated headings, quotations, lists, links, bold and italic text.

This file records the design intent so later typography changes do not accidentally revert the article body to generic application text.
