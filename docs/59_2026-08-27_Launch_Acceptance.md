# Launch acceptance evidence — 27 August

Website go-live is accepted only from measured final surfaces.

1. Freshness: exactly five current-day review-ready drafts, with current operational date/package identity and no stale previous-day article satisfying a slot.
2. Editorial: Publication Review plus deterministic Draft Ready/originality/style checks pass on those exact five.
3. Media: for each exact draft record hero subject and inline subjects/count; no unrelated named person; visible editor/public rendering must agree with Sanity readback.
4. Mobile CMS: authenticated owner phone can read headline, standfirst, body editor and Stored formatted preview with high contrast.
5. Publication: human approval remains mandatory; representative published article renders correctly on production desktop/mobile.
6. Social: if included in launch acceptance, controlled Facebook and Instagram deliveries return provider IDs and duplicate retry does not duplicate posts.

No infrastructure-only proxy is sufficient for these gates.
